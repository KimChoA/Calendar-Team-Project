## 📌 프로젝트 개요

**Moble Calendar**는 사용자의 다양한 일정을 하나의 프로그램에서 관리할 수 있도록 개발한  
**C# WinForms 기반 개인 및 공유 일정 관리 프로그램**입니다.

기본적인 캘린더 기능에 그치지 않고,

- 개인 일정 관리
- 월간 · 주간 · 일간 캘린더
- 스터디 플래너
- 시간표 관리
- 다이어리
- D-Day 및 일정 알림
- 공유 캘린더
- 참여자별 일정 관리
- 공유 캘린더 실시간 채팅
- 공공데이터 기반 공휴일 표시
- 사용자 맞춤 테마 및 글꼴
- 회원 관리 및 마이페이지
- Premium 기능

등을 하나의 프로그램 안에 통합했습니다.

## 🎯 프로젝트 목표

본 프로젝트의 주요 목표는 다음과 같습니다.

- **개인 일정과 학습 일정을 하나의 프로그램에서 통합 관리**
- 월 · 주 · 일 단위로 일정을 직관적으로 확인
- 일정, 다이어리, 플래너, 시간표 간 연결성 강화
- 여러 사용자가 함께 사용할 수 있는 공유 캘린더 구현
- MySQL을 이용한 사용자별 데이터 관리
- 공공데이터 Open API를 활용한 실제 공휴일 정보 연동
- 사용자 설정에 따른 테마와 글꼴 변경
- 팀 단위 기능 개발 및 전체 시스템 통합

## 💡 프로젝트 배경

기존 캘린더 프로그램은 일정 확인에 기능이 집중되어 있어  
학습 계획, 시간표, 다이어리와 같은 정보를 각각 별도의 서비스에서 관리해야 하는 불편함이 있습니다.

본 프로젝트에서는 이를 개선하여,

> **일정 등록 → 학습 계획 → 시간표 → 기록 → 일정 공유**

까지 하나의 프로그램에서 관리할 수 있는  
**통합 일정 관리 환경**을 구현하고자 했습니다.

또한 개인 일정 관리뿐만 아니라  
공유 캘린더와 채팅 기능을 추가하여 친구나 팀원과 일정을 함께 관리할 수 있도록 확장했습니다.

# ✨ 주요 기능

## 👤 1. 회원 관리

- 회원가입
- 로그인
- 로그인 ID 저장
- 사용자별 데이터 관리
- 회원정보 수정
- 회원 탈퇴
- Premium 사용자 상태 확인
- 마이페이지 제공

사용자별 일정과 설정을 구분하여 관리할 수 있도록  
**MySQL 기반 회원 시스템**을 구성했습니다.

---

## 📅 2. 개인 캘린더

개인 일정 등록 및 관리를 위한 메인 캘린더 기능입니다.

- 일정 생성 / 수정 / 삭제
- 일정 제목 및 시간 설정
- 일정별 카테고리 관리
- 반복 일정 설정
- 일정별 색상 적용
- 날짜별 일정 조회
- 일정 검색

### Calendar View

캘린더는 다음 세 가지 보기 방식을 지원합니다.

| 보기 | 설명 |
|---|---|
| **월간 보기** | 한 달 전체 일정 확인 |
| **주간 보기** | 선택된 주의 일정 확인 |
| **일간 보기** | 특정 날짜의 상세 일정 확인 |

동일한 일정 데이터를 기준으로  
월간 · 주간 · 일간 화면이 함께 연동되도록 구현했습니다.

---

## 🔁 3. 반복 일정

반복적으로 발생하는 일정을 한 번의 설정으로 등록할 수 있습니다.

- 반복 없음
- 일간 반복
- 주간 반복
- 월간 반복
- 반복 종료 날짜 설정

일정 생성 시 반복 조건을 저장하고  
각 날짜에 맞게 일정이 표시되도록 구성했습니다.

---

## 🗂️ 4. 사용자 카테고리 관리

사용자가 직접 일정 카테고리를 생성하고 관리할 수 있습니다.

- 카테고리 추가
- 카테고리 수정
- 카테고리 삭제
- 카테고리별 일정 구분
- 색상 기반 일정 시각화

이를 통해 업무, 학교, 약속 등  
일정 유형을 시각적으로 구분할 수 있도록 했습니다.

---

## 📖 5. 다이어리

날짜별 기록을 저장할 수 있는 다이어리 기능입니다.

- 날짜별 다이어리 작성
- 기존 내용 수정
- 기록 삭제
- 월간 · 주간 · 일간 보기
- 캘린더 날짜와 동기화

일정 관리뿐 아니라  
사용자의 하루 기록까지 하나의 프로그램에서 관리할 수 있도록 구성했습니다.

---

## 📚 6. 스터디 플래너

날짜별 학습 계획과 실제 공부 시간을 관리할 수 있습니다.

### 주요 기능

- 날짜별 학습 계획 관리
- 체크리스트 기반 공부 항목 관리
- 공부 시간 입력
- 시간대별 학습 계획 표시
- 과목별 학습 시간 관리
- 학습 완료 여부 체크
- **오늘의 총 공부시간 자동 계산**
- 캘린더 날짜 선택과 플래너 연동

캘린더에서 날짜를 변경하면  
해당 날짜의 플래너 데이터가 자동으로 불러와지도록 구성했습니다.

---

## 🏫 7. 시간표

수업 및 정기 일정을 시간표 형태로 관리할 수 있습니다.

- 수업 추가 / 수정
- 요일 및 시간 설정
- 과목별 색상 표시
- 오늘의 수업 확인
- 현재 수업 진행 상태 표시
- 시간표 기반 일정 시각화

일반적인 캘린더와 별도로  
학교 수업처럼 반복되는 일정은 시간표 형태로 확인할 수 있습니다.

---

## 👥 8. 공유 캘린더

여러 사용자가 하나의 캘린더를 함께 사용할 수 있는 기능입니다.

### 주요 기능

- 공유 캘린더 생성
- 공유 캘린더 참가
- 사용자 초대
- 이메일 기반 초대
- 멤버 목록 관리
- 멤버 권한 관리
- 공유 캘린더 탈퇴
- 공유 캘린더 삭제
- 공유 일정 생성 / 수정 / 삭제

공유 캘린더에서는 여러 사용자가 동일한 일정을 확인하고  
함께 관리할 수 있습니다.

---

## 🎨 9. 공유 일정 참여자 색상 구분

여러 명이 참여하는 일정에서도 사용자를 쉽게 구분할 수 있도록  
**참여자별 Color Index 기반 색상 시스템**을 적용했습니다.

- 공유 캘린더 참가 시 사용자별 고유 색상 할당
- 일정 생성 시 전체 참여 또는 특정 참여자 선택
- 일정 참여자별 색상 Indicator 표시
- 여러 명이 참여한 일정에서는 여러 색상을 동시에 표시

이를 통해 공유 일정에서도  
**누가 해당 일정에 참여하는지 한눈에 확인**할 수 있도록 했습니다.

---

## 💬 10. 공유 캘린더 채팅

공유 캘린더 구성원 간 의사소통을 위한 채팅 기능입니다.

- 공유방별 채팅
- 사용자별 메시지 구분
- 이전 채팅 내역 불러오기
- 메시지 전송
- 시간 정보 표시
- 공유방 참여 인원 표시

캘린더와 별도의 메신저를 이용하지 않고도  
공유 일정과 관련된 내용을 프로그램 안에서 바로 소통할 수 있도록 구현했습니다.

---

## 📧 11. 공유 캘린더 이메일 초대

공유 캘린더 생성 및 사용자 초대 시  
SMTP를 이용해 초대 메일을 전송할 수 있도록 구성했습니다.

```text
공유 캘린더 생성
        ↓
초대 대상 입력
        ↓
초대 정보 생성
        ↓
SMTP 이메일 발송
        ↓
사용자 공유 캘린더 참가
```

---

## 🔴 12. 공공데이터 공휴일 API 연동

공공데이터포털의 **공휴일 Open API**를 연동하여  
대한민국 공휴일을 캘린더에 자동 표시합니다.

- Open API 요청
- 응답 데이터 파싱
- 날짜 / 공휴일명 추출
- 캘린더 날짜와 매칭
- 공휴일 자동 표시
- 월간 · 주간 · 일간 화면 공통 적용

API 호출 중에도 UI가 멈추지 않도록  
비동기 데이터 처리를 적용했습니다.

---

## ⏰ 13. D-Day

사용자가 중요한 일정이나 날짜를 D-Day로 설정할 수 있습니다.

- 기존 일정에서 D-Day 선택
- 새로운 D-Day 생성
- D-Day 저장
- D-Day 삭제
- 메인 화면에서 남은 날짜 표시

중요한 시험, 약속, 기념일 등을  
메인 화면에서 빠르게 확인할 수 있도록 구성했습니다.

---

## 🔔 14. 일정 알림

등록된 일정의 알림 시간을 확인하여  
사용자에게 일정 알림을 제공하는 기능입니다.

- 일정 알림 여부 확인
- 현재 시간과 일정 시간 비교
- 등록된 캘린더 일정 확인
- 조건 만족 시 알림 표시

---

## 🔍 15. 일정 검색

캘린더에 등록된 데이터를 검색하여  
원하는 일정을 빠르게 찾을 수 있도록 구성했습니다.

검색 결과는 별도의 결과 화면에 표시되어  
해당 일정 정보를 바로 확인할 수 있습니다.

---

## 🎨 16. 사용자 맞춤 테마

사용자가 원하는 분위기에 맞게  
프로그램의 테마를 변경할 수 있습니다.

### 지원 테마

- Light
- Dark
- Blossom
- Mint
- Lavender
- Cozy

선택한 테마는 DB에 저장하여  
다음 로그인 시에도 사용자의 설정이 유지되도록 구현했습니다.

---

## 🔤 17. 글꼴 변경

사용자 설정에 따라 프로그램 전체 글꼴을 변경할 수 있습니다.

지원하는 글꼴 예시:

- 맑은 고딕
- 바탕체
- 돋움
- 한컴 말랑말랑
- 훈민정음 가로쓰기
- 한컴 산뜻돋움

캘린더의 레이아웃이 글꼴 크기에 영향을 받지 않도록  
컨트롤별 글꼴 적용 구조를 분리했습니다.

# 👑 Team Leader & My Contribution

본 프로젝트에서 **김초아는 팀장으로 참여하여 캘린더 핵심 기능과 사용자 경험 개선을 중심으로 개발했습니다.**

## ✅ 담당 역할

### **1. 공유 캘린더 참여자 식별 및 일정 시각화**

- 공유 캘린더 참가 시 사용자별 고유 `Color Index` 자동 할당
- 일정 생성 시 전체 참여 또는 특정 참여자 선택 기능 구현
- 참여 인원별 색상 Indicator 동적 렌더링
- 여러 사용자가 참여하는 일정에서 색상 동시 표시

이를 통해 공유 일정에서  
**어떤 사용자가 일정에 참여하는지 직관적으로 확인**할 수 있도록 개선했습니다.

---

### **2. 공공데이터 API 연동 및 공휴일 자동 반영**

- 공공데이터포털 공휴일 Open API 연동
- API 응답 데이터에서 날짜 및 공휴일명 추출
- 공휴일 데이터와 캘린더 날짜 매칭
- 월간 · 주간 · 일간 캘린더에 공통 적용
- 비동기 처리를 통한 UI 응답성 유지

공휴일 정보를 직접 입력하지 않아도  
캘린더에 자동으로 표시되도록 구현했습니다.

---

### **3. 캘린더 연동형 스터디 플래너**

- 체크리스트 기반 학습 계획 관리
- 날짜별 학습 데이터 저장
- 캘린더 날짜 선택과 스터디 플래너 데이터 연동
- 시간대별 학습 계획 구성
- **오늘의 총 공부시간 자동 계산**

캘린더와 별개의 플래너가 아니라  
**선택된 날짜를 기준으로 일정과 학습 계획을 함께 관리**할 수 있도록 구성했습니다.

---

### **4. 사용자 맞춤형 테마 및 UI 개선**

- Light / Dark 등 사용자 선택형 테마 적용
- 캘린더, 다이어리, 플래너, 시간표 주요 화면에 동일 디자인 규칙 적용
- 프로그램 전체 글꼴 변경 기능 구현
- 사용자별 테마 / 글꼴 설정 저장
- 글꼴 변경 시 WinForms 컨트롤 크기 변형 문제 개선

기능 구현뿐만 아니라  
사용자가 장시간 사용하는 일정 관리 프로그램의 특성을 고려하여  
**가독성과 UI 일관성 개선**에 집중했습니다.

# 🛠 문제 해결

## 1. 스터디 플래너 날짜별 데이터 표시 오류

### 문제

캘린더 날짜를 변경했을 때  
스터디 플래너의 데이터가 즉시 갱신되지 않거나  
이전 날짜의 데이터가 유지되는 문제가 발생했습니다.

### 해결

- 캘린더 날짜 선택 이벤트를 기준으로 데이터 로드
- 각 화면에서 개별적으로 날짜를 관리하던 구조를 하나의 선택 날짜 기준으로 통일
- 날짜 변경 시 플래너 화면을 함께 갱신하도록 처리

이를 통해 캘린더와 스터디 플래너 간 날짜 연동을 안정화했습니다.

---

## 2. 글꼴 변경 시 캘린더 크기 변형

### 문제

사용자가 글꼴이나 글자 크기를 변경하면  
WinForms의 자동 크기 조정으로 인해 캘린더 셀과 전체 레이아웃이 함께 변형되는 문제가 발생했습니다.

### 해결

- 캘린더 영역의 크기를 고정
- `AutoSize` 및 Layout 설정 조정
- 글꼴 적용 로직과 UI 크기 조정 로직 분리
- 사용 가능한 글꼴 크기 범위를 제한

글꼴을 변경해도 기존 캘린더 구조가 유지되도록 개선했습니다.

---

## 3. 공휴일 화면 연동 문제

### 문제

초기에는 공휴일 API 데이터가 월간 캘린더에만 적용되어  
주간 및 일간 화면에서는 공휴일이 표시되지 않는 문제가 있었습니다.

또한 화면마다 데이터를 별도로 처리하면서  
동일한 공휴일 정보가 모든 캘린더에 공유되지 않았습니다.

### 해결

- 공휴일 데이터를 공통 데이터 구조로 관리
- 날짜 기준 공휴일 확인 로직 통합
- 월간 · 주간 · 일간 화면에 동일 데이터 적용

이를 통해 어떤 캘린더 보기에서도  
동일한 공휴일 정보가 표시되도록 수정했습니다.

# 🔐 공개 저장소 보안

DB 접속 정보, 공공데이터 API Key 및 이메일 인증정보는  
GitHub에 직접 포함하지 않고 **환경 변수로 분리**했습니다.

사용되는 환경 변수:

```text
MOBLE_DB_CONNECTION
MOBLE_HOLIDAY_API_KEY
MOBLE_SMTP_EMAIL
MOBLE_SMTP_APP_PASSWORD
```

이를 통해 소스 코드는 공개하면서  
실제 인증정보는 저장소에 노출되지 않도록 구성했습니다.

# 🚀 빌드 및 실행

## 1. 개발 환경

- Windows
- Visual Studio 2022

- MySQL

## 2. 실행

1. 필요한 환경 변수를 설정합니다.
2. MySQL 데이터베이스 환경을 구성합니다.
3. `Moble_Team_Project.sln`을 Visual Studio에서 실행합니다.
4. NuGet 패키지를 복원합니다.
5. 프로젝트를 빌드 및 실행합니다.
